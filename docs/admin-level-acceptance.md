## 四种身份分开

账号等级为 1–10；客户管理权限、房间成员/管理员角色与设备等级独立。新设备、旧设备及受邀设备默认普通设备（0级），房间管理员身份不自动升级设备等级。10级账号也不是超级管理员。

普通 N 级管理员在已有管理权限范围内，只能把低等级设备提升到自己的 N 级，不能任选中间等级或越级。超级管理员可选择设备提升等级；现有设备接口只提升，不支持降级。只有超级管理员能上调或下调普通账号等级；写操作须携带当前 revision。

有效控制等级为 min(已验证设备等级，服务器登记的设备所有者账号等级上限)。在同客户、同一已批准房间内，有效控制等级达到目标等级时，不再额外走逐设备白名单；控制高等级设备须原目标审批，返回 ROOM_SIMULATION_HIGHER_LEVEL_APPROVAL_REQUIRED。设备身份、来源门禁、目标有效授权、票据、工具和系统权限仍需满足。账号降级会动态限制现有设备及票据；不承诺撤回已发生的副作用。

修改昵称、自报 admin 或传入账号名称均不产生权限。客户端账号登录及同账号多设备自动互信仍属后续研发，不能把后台登录或数据库 owner 字段当作已实现的客户端可信绑定。
