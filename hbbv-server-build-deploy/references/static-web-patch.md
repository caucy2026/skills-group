# hbbv 静态网页的原子补丁与清场

仅当改动限于运行服务每次HTTP请求重新读取的 `web/` 文件，且后端模块、API、数据库和服务参数无需改变时使用。先从当前 `systemctl show` 取实际 `WorkingDirectory`、PID/出生时间、active状态和服务ID；不要按旧文档猜 `current` 符号链接。核本地已推主线的精确文件与线上旧文件SHA，确认差异只属于本次授权改动；若线上与父版本不一致，先合并差异，不直接覆盖。查正式发布清单的基础提交、既有网页补丁及外部目录链接。

在本机按环境规则准备独立计划：旧/新SHA、文件字节、原PID/出生时间、serverId、发布目录、源提交与唯一暂存目录。用合成发布树实际验一次应用和回滚；多文件事务再故障注入中途失败，确认原字节恢复。网页功能用隔离账号和真实浏览器验证，不用生产密码作测试数据。部署资格、共享工作和实际设备事务仍须现场核对。

经已保存且指纹匹配的服务器SFTP把精确文件、计划和一次性脚本传入权限700的独立暂存；上传后逐项哈希。执行时独占项目原有 `.deployment.lock`，再次核原服务PID/出生时间/工作目录、serverId、旧文件SHA与清单状态。先在暂存保留原静态文件及清单作为短期回滚，再逐文件以同目录临时文件加 `os.replace` 原子替换；更新发布清单的文件SHA和本次网页源码提交，保留原基础发布身份。原执行结果未知时先查同一事务回执和线上字节，不重跑补丁。若任一步失败，按预备的原字节回滚；不能清DB、换身份或重启服务掩盖网页错误。

通过公网HTTPS实际GET每个改动资源，核200、字节、SHA和缓存头，再用浏览器核需要的交互与脚本错误。复核原serverId/PID、房间心跳、项目容量与3GB上限。只有静态文件读取路径已证无需重启时才保持服务运行；Python代码、API路由、运行配置、签名或DB变更走完整服务部署与本地一致性备份门禁。静态补丁也不能把合成账号页面通过写成生产真实用户、设备授权或数万账号验收。

结果确认后下载回执，逐项清理本任务云端暂存和已无恢复用途的短期静态回滚副本，回读路径不存在。记录删除文件数/逻辑字节、卷可用字节前后、项目实际占用、仍保留的正式发布/源码/证据；不把逻辑删除量冒称独占净空闲增长，不碰其他会话产物或数据库。2026-11-05/06的三文件账号页和单文件管理标题生产实例、原PID保持与云端清理见私有项目 `hbbv/docs/acceptance/G05_G07_ACCOUNT_UI_STATIC_PRODUCTION_20261105.md`；该路径仅是实证，不是可照抄的设备、域名或参数模板。
