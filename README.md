# VibeKits 集群团队技能

从 [vibekits-cluster-operations/SKILL.md](vibekits-cluster-operations/SKILL.md) 开始，包含仿真、后台、客户/管理员、房间审批与成员通信、任务、监控、升级和清理的完整操作入口及随包资料。

把整个 `vibekits-cluster-operations` 文件夹安装到自己环境的技能目录，例如 `~/.codex/skills/`，然后使用 `$vibekits-cluster-operations`。不要只复制 SKILL.md；references 和调用脚本需要一起保留。使用自己的已授权账号和设备清单，凭据不在仓库。

公开下载与使用指南：https://kemi-chat.newlinksz.com:21122/vibekits/ 。包含四端商城入口、同站后台连接地址，以及给智能体的 agent.json / llms.txt。完整从零操作指南见 [getting-started.md](vibekits-cluster-operations/references/getting-started.md)。Linux未有正式包时明确待上架。
