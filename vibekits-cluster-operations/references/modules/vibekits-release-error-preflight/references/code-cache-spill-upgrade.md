# W15/W49/W61：升级前保存旧 SDK spill

Android 的 code_cache 会在应用或平台升级时由系统删除。业务工具输出和被 SDK 会话引用的 spill 不是可丢弃编译缓存。参考：https://developer.android.com/reference/android/content/Context#getCodeCacheDir()

覆盖安装前必须盘点旧版 spill。非空旧 spill 必须先有逐文件大小/SHA及原路径对应的、已独立认证的完整保存或迁移证据；只有旧 chat/Key 完整、签名相同、pm install -r、不卸载，都不足以保护 code_cache。完整快照若明确 legacy_home_not_covered，不得继续覆盖并宣称旧输出已保全。不要以新代码支持读取旧路径、升级后新目录正常，代替升级前保护。

使用获授权的旧宿主只读/保存入口，按实际 writer/cut 规则保存完整字节。保留原 locator，恢复必须精确对应原文件；未知文件和未知在途写不删除。不能读出/认证保存时，保留旧宿主与事务，继续其他工作，不伪造恢复或用重新生成文件代替原 SHA。

新版本未来输出必须落持久 files 范围，写前合计配额，禁年龄清理被引用的数据；实际大输出读取、完整备份、同签覆盖/重装后原 locator 内容及 SHA均验收。系统确认按实际平台权限，不强造弹窗。
