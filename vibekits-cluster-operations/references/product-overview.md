# 产品机制与场景

全球设备，一间工作室：把散布各地的电脑、PAD 与专业工具连接到同一个获批房间，按任务共享能力，像坐在一起工作。

1. 设备成为团队资源：本机写代码，可借用获授权房间 Windows 的编译环境、Mac 的签名能力、PAD 的现场调试能力。
2. 跨地域连接：用原仿真 ID 经 P2P 或中继连接不同网络；PAD 远程 ADB 使用控制端动态本机端点，不要求同一局域网，不公开设备 5555。
3. 一份工具合同：智能体、专业界面、文档和测试复用稳定工具 ID、Schema、权限与结果语义；实际平台支持仍需目录和调用确认。
4. 可验证交付：以实际产物、签名、哈希和设备反馈证明完成。在线、已发现、已分配和已执行分别验证。

产品目标不代表任意网络、离线或未授权设备都可连接。入房不自动授予业务执行、证书或发布账号使用权；当前任务、本机许可、组件和系统权限仍须有效。高级调度、评分及规模能力按当前版本和真实验收确认。
